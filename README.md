# 空拍視角道路阻塞率演算法 程式

## 1. 檔案簡述

`assess_centreline_graph_corridor.py`

內含下列四個版本的全部程式：

1. `reconstruct_road_v1.py`：標註讀取、mask 建立、骨架與道路幾何工具。
2. `assess_centerline_graph_corridor_v1.py`：中心線片段、道路輔助物、橫切片與阻塞判定。
3. `assess_centreline_graph_corridor_v1_2_main_trunk.py`：不限固定斷裂距離的候選連線與單一主要幹道搜尋。
4. `assess_centreline_graph_corridor_v1_3_main_trunk_local_width_prior.py`：局部健康路寬先驗、道路縮限修正及未知區域控制。


## 2. 各版本程式差異

四個版本是逐步疊加的關係，最終版程式(本程式) 會使用前面版本提供的功能。

### 2.1 道路重建基礎工具

對應 `reconstruct_road_v1.py`。

- 將 road、障礙物及道路輔助物 polygon 轉為二值 mask。
- 清理小區塊與孔洞，並將 road mask 骨架化。
- 從骨架取得有順序的道路中心線。
- 沿中心線量測左右道路寬度，並建立道路 polygon。
- 提供圖片讀寫、mask 輸出及基礎視覺化功能。

這一層只負責道路幾何處理。

### 2.2 V1：中心線圖與橫切片判定

對應 `assess_centerline_graph_corridor_v1.py`。

- 將不同 road mask 區塊轉成多條中心線片段。
- 使用 road line、guardrail、roadside wall、curb 協助判斷道路方向與邊界。
- 在限定的斷裂距離、方向及曲率條件內連接中心線片段。
- 依可見道路寬度建立重建道路走廊。
- 沿中心線法線產生橫切片，計算障礙物占比與剩餘連續自由寬度。
- 根據橫切片輸出道路阻塞分類。

主要限制是中心線片段距離過遠時不容易連接，因此道路被大型障礙物完全切斷時可能輸出 `uncertain`。

### 2.3 V1.2：不限固定距離的主要幹道搜尋

對應 `assess_centreline_graph_corridor_v1_2_main_trunk.py`。

- 保留 V1 的中心線與橫切片方法。
- 取消中心線候選連線的固定最大距離限制。
- 將連線距離改成成本，而不是直接淘汰遠距離候選。
- 建立中心線片段圖，從中搜尋一條成本最低的主要道路幹道。
- 只使用選定的主要幹道進行道路重建及阻塞評估。

V1.2 能處理較大的道路斷裂，但缺少足夠方向或道路輔助物時，也可能把相距很遠、實際不相連的道路錯接在一起。

### 2.4 V1.3：局部健康路寬先驗與縮限修正

對應 `assess_centreline_graph_corridor_v1_3_main_trunk_local_width_prior.py`。

- 保留 V1.2 的主要道路幹道搜尋。
- 從遠離障礙物且寬度合理的道路區段估計健康道路寬度。
- 偵測障礙物附近因 road mask 被壓縮而產生的異常窄路段。
- 使用鄰近健康路寬插值，修正預期道路寬度。
- 使用 road line 或道路邊界輔助修正中心線位置。
- 將橫切片分成障礙物、已確認自由空間及未知空間。
- 推測補出的道路只作為阻塞比例的分母，不會直接被視為可通行道路。

V1.3 可降低 road mask 縮限造成的路寬低估，但效果仍依賴 V1.2 是否選到正確的主要幹道。若主要幹道錯誤或完全沒有穿過障礙物，仍可能輸出 `uncertain` 或錯誤分類。

### 2.5 版本演進摘要

| 階段 | 主要新增功能 | 主要解決問題 | 仍存在的限制 |
|---|---|---|---|
| 基礎工具 | mask、骨架、中心線、路寬與 polygon | 建立道路幾何資料 | 不進行阻塞分類 |
| V1 | 中心線連接與橫切片阻塞判定 | 從道路幾何判斷通行程度 | 遠距離斷裂不易連接 |
| V1.2 | 無固定距離上限的單一主要幹道 | 大型障礙物造成的道路斷裂 | 可能連出不存在的遠距道路 |
| V1.3 | 健康路寬先驗、縮限修正與 unknown 控制 | road mask 被障礙物壓縮造成的路寬低估 | 仍依賴主要幹道是否正確 |

簡化理解如下：

```text
基礎工具：找出道路中心線與寬度
    ↓
V1：連接中心線並用橫切片判定阻塞
    ↓
V1.2：允許跨越較大缺口，搜尋單一主要幹道
    ↓
V1.3：修正障礙物附近被低估的道路寬度
```


## 3. 必要套件

需要 Python 3.9 以上及下列套件：

```bash
python -m pip install numpy opencv-python scipy scikit-image
```


## 4. 輸入資料格式

`--json` 不是使用原始 COCO 格式。可接受格式如下：

```json
{
  "items": [
    {
      "key": "image.JPG",
      "width": 5472,
      "height": 3648,
      "road_blockage": "blocked",
      "boxes": [
        {
          "label": "road",
          "points": [
            {"x": 100, "y": 200},
            {"x": 300, "y": 200},
            {"x": 300, "y": 400}
          ]
        }
      ]
    }
  ]
}
```

也可直接以 item 陣列作為 JSON 最外層。


## 5. 演算法流程

1. 將 road polygon 轉成二值道路 mask，移除小區塊並進行小範圍 closing。
2. 對可見道路 mask 骨架化，抽取道路中心線片段。
3. 判斷 road line 是否位於道路內部；足夠接近道路中心時才作為額外中心線。
4. 對任意兩個有效中心線片段建立平滑連線候選。V1.2 不以固定最大距離直接淘汰，而是將距離納入成本。
5. 使用端點方向、曲率、路寬差、road line、guardrail、roadside wall、curb、障礙物支持與邊界穿越比例計算連線成本。
6. 在中心線圖中搜尋一條主要道路幹道，只保留該路徑及其連線。
7. 沿主要幹道量測可見道路左右寬度。
8. 在遠離障礙物且寬度合理的位置建立健康路寬先驗。
9. 道路 mask 在障礙物附近明顯變窄或缺少寬度觀測時，以鄰近健康路寬插值，並利用 road line 或道路邊界修正中心位置。
10. 依照局部中心線、左寬與右寬建立預期道路走廊。推測道路只作為評估分母，不自動當成可通行空間。
11. 沿中心線法線產生橫切片，分別計算障礙物、已確認自由空間及未知空間比例。
12. 根據障礙物占比、剩餘連續自由寬度及嚴重阻塞切片的連續程度輸出 `clear`、`passable_restricted`、`blocked` 或 `uncertain`。


### 主結果 CSV

每張影像一列，包含：

- GT 與預測標籤
- 是否正確、信心與是否需人工檢查
- 道路中心線片段與 bridge 數量
- 主要幹道來源及成本
- 有效橫切片數量
- 障礙物占比、最小自由寬度與嚴重阻塞連續比例
- 道路壓縮偵測與局部路寬先驗統計
- unknown ratio 與錯誤訊息

### `main_trunk_candidates.csv`

記錄所有中心線候選連線、端點方向、距離、輔助物支持、障礙物支持、邊界穿越比例、成本及是否被主要幹道採用。

### `slice_profiles.csv`

記錄每條橫切片的位置、障礙物比例、最大自由寬度、觀測路寬、預期路寬、未知比例與是否可評估。

### `diagnostics/*.json`

記錄每張影像的中心線片段、選定連線、局部路寬先驗、各障礙物 cluster 的判定及最終 `reason`，適合分析 `uncertain`。

## 6. Overlay 顏色

- 綠色半透明 mask：原始可見 road mask。
- 紅色半透明 mask：實體障礙物。
- 淺藍色 mask：重建後新增、原始 road mask 中不存在的道路走廊。
- 黃線：主要道路中心線。
- 紫線：推測連接中心線片段的 bridge。
- 橘點：啟用局部路寬校正的位置。
- 白色橫線：一般可評估切片。
- 紅色橫線：達到嚴重阻塞條件的切片。
